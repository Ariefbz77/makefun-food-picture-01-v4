A program that copies a mouth-watering picture — an extreme close-up of a double smash cheeseburger filling the whole frame, molten cheddar and glossy burger sauce cascading down two crispy-edged patties, a shiny sesame brioche bun, steam rising in warm golden light — to /output/entry.png for make.fun's food-picture-01 bounty.

Round 3: round 1's ramen (91.1% judge win rate) proved steam plus gloss wins, and round 2's pizza proved a single melt moment wins. This one stacks both on the most craveable subject there is — and drops the hand entirely, so no finger or grip can break the illusion. One hero dish, no text, no hands: melt, drip, steam and gloss, readable at 300 pixels.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
